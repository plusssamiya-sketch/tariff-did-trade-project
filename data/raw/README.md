# Raw Data

This folder documents raw inputs for the portfolio package.

## Included Files

- `sample_trade_flows.csv`: synthetic province-destination-month export values.
- `sample_controls.csv`: synthetic province-month controls.

These files are not real customs data. They exist so reviewers can inspect the expected data structure and run the scripts after substituting real or anonymized data.

## Intended Real Data Sources

For a full coursework version, raw data should be documented as:

- Chinese province-destination-month export values, November 2024-April 2025.
- Destination policy exposure classification.
- Exchange-rate controls.
- Province-level GDP growth and inflation controls.

## Access Conditions

Do not commit:

- paid database exports
- private course files
- confidential raw data
- data that cannot be redistributed

If a raw source is restricted, document the source name, access route, variable list, and cleaning steps without uploading the restricted file.
