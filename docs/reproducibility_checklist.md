# Reproducibility Checklist

This checklist is for keeping the course project folders easy to inspect later.

## Package Structure

- [x] README states the research question, unit of observation, period, method, and master script.
- [x] Raw data folder documents source and access restrictions.
- [x] Processed data is generated by code.
- [x] Code is modular and numbered in execution order.
- [x] Outputs are separated into tables and figures.
- [x] Brief/memo is stored separately from code and data.

## Data

- [x] Committed data are synthetic/sample and marked as such.
- [x] Restricted data should not be uploaded.
- [x] Data dictionary documents raw and constructed variables.

## Code

- [x] `code/00_master.do` runs scripts in order.
- [x] Scripts create output directories if missing.
- [x] Scripts write a log or manifest.
- [ ] Stata execution should be verified on a machine with Stata installed.

## Outputs

- [x] Expected tables and figures are named in README files.
- [x] Research brief references the expected tables and figures.
- [x] Interpretation separates coursework results from stronger causal claims.
